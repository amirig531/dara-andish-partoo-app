# اپلیکیشن دارا اندیش پرتو

کاتالوگ آفلاین‌محور خودروها و قطعات قابل تأمین مجموعه با رابط فارسی و راست‌چین.

## امکانات
- فهرست 31 مدل خودرو با تصاویر استخراج‌شده از فایل Word
- صفحه اختصاصی هر خودرو و گروه‌بندی قطعات مطابق ساختار کاتالوگ
- جستجوی نام خودرو و جستجوی قطعه در کل فهرست
- صفحه معرفی مجموعه و نشانی درج‌شده در سند
- رابط واکنش‌گرا برای موبایل و دسکتاپ، قابل نصب به‌صورت PWA و دارای کش آفلاین برای فایل‌های بازدیدشده
- ساخت APK اندروید با GitHub Actions

## اجرای محلی
نیازمند Node.js 20 یا بالاتر:
```bash
npm install
npm run dev
```

برای ساخت نسخه وب:
```bash
npm run build
```

## گرفتن APK از GitHub
1. فایل ZIP را از حالت فشرده خارج کنید.
2. کل محتویات پوشه را در یک repository جدید GitHub بارگذاری کنید.
3. به زبانه **Actions** بروید.
4. گردش‌کار **Build Android APK** را انتخاب و روی **Run workflow** کلیک کنید؛ با هر push به شاخه main یا master نیز اجرا می‌شود.
5. پس از اتمام موفق، در بخش Artifacts فایل `dara-andish-partoo-debug-apk` را دانلود کنید. داخل آن `app-debug.apk` قرار دارد.

## محتوای کاتالوگ و محدودیت داده
نام خودروها، تصاویر و فهرست گروه‌ها و قطعات از فایل `APP.docx` استخراج شده‌اند. آدرس مجموعه نیز مطابق سند درج شده است:
**تهران – شهران – بین فلکه دوم و سوم – ساختمان ماهان**

در سند قیمت، موجودی لحظه‌ای، شماره تماس یا امکان ثبت سفارش ارائه نشده؛ بنابراین این نسخه آن موارد را نمایش نمی‌دهد و چیزی را حدس نمی‌زند.

## تغییر اطلاعات
اطلاعات خودروها در `src/vehicles.json` قرار دارد و تصاویر در `public/cars/`. برای تغییر لوگو، فایل `public/brand-logo.png` را جایگزین کنید.
